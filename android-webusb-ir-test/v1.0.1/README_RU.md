FC/7001 теперь распознаётся отдельно от FB; профиль допускает один FA после FC7001. Значение XY и влияние нового handshake на устойчивость ещё требуют проверки на устройстве. Длина FE остаётся big-endian, последний 75 не является критерием полноты.

После тайм-аута неполной сборки страница сохраняет буфер и raw RX в карантине, блокирует новые протокольные TX. Нажмите **«Программно переподключить»**: выполняются close/open ранее разрешённого USB-устройства. Это не firmware-reset и не доказательство восстановления; нужны новые полные FE. При ошибке close повторите «Отключить»: открытие второго сеанса запрещено до успешного закрытия.

Проверьте одиночное нажатие, 10 последовательных нажатий с паузами не менее 1 с, отдельное удержание и три программных переподключения. Сохраните JSON. При воспроизведении ошибки сохраните журнал до и после программного reconnect. Счётчик FE не доказывает соответствие числу физических нажатий; проверяйте полные RX и длины.

Автономные проверки из каталога v1.0.1:

```sh
node --test tests/*.test.cjs
```

23 проверки пройдены; ни одного аппаратного PASS новой версии нет. Доступ из среды разработки к Wireless ADB отсутствует. Windows-скрипты находятся в automation; инструкции — в QA_REPORT. Нужен PowerShell 7.2+, ADB, уже сопряжённый разблокированный Xiaomi. Старый комплект автоматизации v1.0.0 не адаптируется молча: используйте новую копию automation.

Если mDNS не видит новый порт в локальной сети, передайте `-Address '172.25.65.11:НОВЫЙ_ПОРТ'`; скрипт не меняет безопасность, не выполняет pairing и не сканирует подсеть. Неизвестная разметка USB-диалога останавливает прогон с UI XML. Для фактического имени устройства можно задать `-UsbDeviceLabelPattern`.
