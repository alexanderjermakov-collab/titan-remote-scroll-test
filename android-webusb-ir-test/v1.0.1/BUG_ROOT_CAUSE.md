# Причины ошибок и проверяемые гипотезы

## Доказано

| Дефект | Причина / свидетельство | Исправление |
|---|---|---|
| FC/7001 — unknown | Набор маркеров v1.0.0 включает только FA/FB/FE; real RX final seq123 и unknown seq124 | Добавлен FC/6, отдельная identify-ветка |
| Ложный identify deadline | identifySeen устанавливался только на FB; отсутствие FB ошибочно означало отсутствие ответа | Явные FC/FB responseType; FA сам по себе не заменяет ответ FC |
| Вечная блокировка после timeout | tick присваивает blocked=true и очищает buffer; сброса внутри Parser нет | Карантин с сохранением буфера и явный software reconnect |
| Частичный заголовок не имеет тайм-аута | incompleteFE требует минимум 4 FE; 1–3 байта не проверяются | Дедлайны любой начатой сборки и состояние header/payload |
| Потенциальное поглощение следующего сообщения | При неизвестной правильности length маркеры внутри payload считаются данными | Не подменять доказательство эвристикой; карантин и новая USB-generation |

## Не доказано

1. Причина недостающих FE-байтов. Big-endian согласуется с 19 полными FE; изменение длины, её порядка или отсечение по 75 отвергнуты как неподтверждённые. Ни один алгоритм не может восстановить отсутствующие 150 байтов из текущего журнала.
2. Что FA после FC/7001 обеспечит стабильный learn. Независимый первичный проект того же VID/PID подтверждает такой handshake, но наши аппаратные логи не сравнивают его контролируемо. Это изменение требует A/B-испытания.
3. Что close/open очищает аппаратное состояние learning. Старые испытания подтверждают USB reopen, но не устойчивое восстановление FE. v1.0.1 не объявляет firmware-reset или подтверждённую ресинхронизацию только по close.
4. Что один FE соответствует одной физической кнопке; независимого измерения излучённых кадров нет.

## Результат автономной проверки исходной гипотезы

Дедупликация по startedUtc/seq даёт 22 FE-наблюдения: 19 полных и 3 неполных. Все полные имеют точное число объявленных байтов; все неполные остаются неполными. Все полные и два неполных заканчиваются 75, поэтому правило завершения по 75 дало бы как минимум два ложных полных кадра. В payload наблюдаемых пакетов нет внутренних четверных маркеров FA/FB/FC/FE — журналы не доказывают фактическое слияние независимых сообщений, только возможность такого дефекта при испорченной длине.

Подробные результаты кода и тестов — в QA_REPORT_v1.0.1.md; аппаратные исходные испытания относятся к v1.0.0, не к новой версии.
